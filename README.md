## About 📖

SIV System Information (System Information Viewer) is a long running hardware inventory tool maintained by Ray Hinchliffe and distributed through the official SIV project pages. It walks the SMBIOS tables, ACPI namespace, PCI bus and SATA/NVMe controllers to build a full picture of the machine, then presents the result as sortable trees and live graphs. Recent builds add improved sensor polling on newer Intel and AMD platforms, better NVMe SMART reporting and refreshed GPU detection for current graphics cards.

If you came looking for a SIV System Information download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The utility runs without a background service, keeps its settings in a local INI file and can be carried on a USB stick for diagnostics on other machines.

**Good for:** PC builders checking component IDs · IT technicians auditing fleets · overclockers monitoring voltages and temperatures · repair shops logging drive health · enthusiasts tracking fan curves · students learning about SMBIOS and ACPI data · anyone verifying RAM timings and slot population.

## Features 🔑

| | |
|---|---|
| 🧩 **Hardware inventory** | Lists CPU, motherboard, chipset, RAM modules, GPUs, drives and network adapters with vendor and model strings. |
| 🌡️ **Live sensor panel** | Shows temperatures, voltages and fan speeds with rolling graphs you can pin to the desktop. |
| 💽 **Drive health view** | Reads SMART attributes from SATA and NVMe drives, including power on hours and reallocated sectors. |
| 🧠 **Memory detail** | Reports slot population, part numbers, timings, ranks and XMP or EXPO profiles per module. |
| 🔌 **Device tree** | Browses PCI, USB and ACPI devices with raw IDs so you can match unknown hardware to drivers. |
| 📈 **Logging** | Records sensor readings to CSV for later review in a spreadsheet. |
| 🖥️ **Multi monitor info** | Reads EDID data from connected displays, including resolution, refresh rate and panel maker. |
| 🧳 **Portable mode** | Runs from a folder or USB stick with no installer required. |
| ⚙️ **Command line** | Supports scripting flags for silent reports, useful in batch inventory jobs. |

## Troubleshooting 🛠️

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Sensors show no readings | Run SIV as administrator so it can reach the hardware monitoring drivers. |
| Fan speeds missing | Update the motherboard chipset driver, some boards hide the Super I/O sensors until then. |
| NVMe drive not listed | Check that the drive is visible in Disk Management, then rescan from the SIV menu. |
| Window opens very small on a 4K screen | Change the display scaling in SIV options, or set compatibility DPI override in the shortcut. |
| CSV log is empty | Confirm the target folder is writable and that logging was started before the capture window. |
| GPU name shows as generic | Install the current graphics driver from your card vendor, then restart SIV. |
